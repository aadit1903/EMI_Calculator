**EMI Calculator**
==================

**Overview**
------------

The **EMI Calculator** is a web-based application that allows users to calculate Equated Monthly Installments (EMIs) for various items such as Cars, Bikes, Phones, Laptops, and more. It provides a user-friendly interface where users can input loan amount, interest rate, and tenure to instantly view their monthly EMI. The application is useful for planning and budgeting before making a purchase.

**Features**
------------

*   **EMI Calculation:** Computes monthly EMI based on user inputs.
    
*   **Category Selection:** Allows EMI calculation for various categories like Car, Bike, Phone, etc.
    
*   **Real-time Results:** Displays EMI, total interest, and total payment instantly.
    
*   **Responsive Design:** Fully responsive and mobile-friendly interface.
    
*   **Interactive UI:** Clean and intuitive layout for better user experience.
    

**Technologies Used**
---------------------

*   **HTML, CSS, JavaScript** for frontend development
    
*   **Math Logic** for EMI calculation formula implementation
    

**How to Run**
--------------

1.  please visit: [https://aadit1903.github.io/EMI\_Calculator/](https://aadit1903.github.io/EMI_Calculator/)
    
2.  Enter the loan amount, interest rate, and loan tenure.
    
3.  Click "Calculate" to view EMI details.
